# ADR-005: 竞品图片分析选用 GPT-4o Vision

## Status
Accepted

## Date
2026-04-17

## Context

项目需要对 Amazon 竞品主图进行自动化分析，提取以下信息：
- 构图方式（主体位置、留白比例）
- 色调风格（主色调、冷暖倾向）
- 使用场景（户外/室内/纯白背景等）
- 视觉标签（对应三层标签体系中的视觉特征标签）

分析结果将作为提示词生成的输入，直接影响最终图片质量。因此分析准确性是核心指标。

## Decision

竞品图片分析选用 **GPT-4o Vision**（通过 OpenAI API 调用）。

每张图片发送一次 API 调用，返回结构化 JSON 分析结果。

## Consequences

### Positive
- 分析质量高：GPT-4o 在复杂视觉理解（构图、风格、场景判断）方面表现优秀
- 支持结构化输出：可通过 `response_format: json_object` 直接返回可解析的 JSON
- API 稳定，文档完整，团队已有使用经验

### Negative
- API 成本约 $0.005/张（含图片 token），批量分析时需要控制节奏
- 依赖外部服务：网络不稳定或 OpenAI 服务波动时会影响流程
- 输出结果不完全可控，存在偶发的幻觉或格式不符，需要做输出校验

## Alternatives Considered

| 方案 | 优点 | 缺点 | 未选原因 |
|------|------|------|----------|
| Gemini 2.0 Flash | 成本更低（约 $0.001/张），速度快 | 复杂视觉推理精度略低于 GPT-4o | 分析质量是核心指标，精度优先 |
| 本地 Qwen2-VL-72B | 零 API 成本，数据不出境 | 需要高端 GPU（80G+ VRAM），本地环境不具备 | 硬件条件限制 |
