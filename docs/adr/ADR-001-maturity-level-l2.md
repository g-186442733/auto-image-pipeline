# ADR-001: MVP 起步成熟度选择 L2

## Status
Accepted

## Date
2026-04-17

## Context

项目路线图定义了 L1 到 L5 五个成熟度等级：

- **L1**：单工具手动操作，无结构化流程
- **L2**：多工具并行，模板驱动，人工触发每个步骤
- **L3**：事件驱动流水线，步骤自动串联
- **L4**：全自动化，含反馈闭环
- **L5**：自优化，AI 驱动决策

MVP 阶段需要选择一个起步级别，目标是尽快验证核心流程，同时不过度工程化。

## Decision

MVP 起步选择 **L2**（多工具并行，模板驱动 + 人工触发）。

具体含义：每个处理步骤（竞品分析、提示词生成、图片生成、质检等）作为独立工具实现，数据格式标准化，但步骤之间由人工手动触发，不自动串联。

## Consequences

### Positive
- 快速验证核心流程的可行性，不被基础设施复杂度拖累
- 标准化数据格式（JSON Schema）为 L3+ 自动串联提前铺路
- 每步可独立调试，问题定位清晰
- 人工介入每步，早期可以观察中间产物、及时修正

### Negative
- 无法自动串联步骤，每次运行需要手动触发多个工具
- 人工操作依赖在 L3 升级时需要被替换，存在返工成本
- 缺乏整体进度可视化，多步骤状态需人工追踪

## Alternatives Considered

| 方案 | 优点 | 缺点 | 未选原因 |
|------|------|------|----------|
| L1 单工具手动 | 最简单，零门槛 | 无结构化，难以复现，无法积累数据 | 太原始，无法支撑后续迭代 |
| L3 事件驱动流水线 | 自动化程度高，步骤串联 | 需要消息队列或编排引擎，初期复杂度过高 | 在核心流程验证之前引入过多基础设施风险 |
